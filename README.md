# Enlaces de Mauricio González

Página personal de enlaces inspirada en [gndx.io](https://github.com/gndx/gndx.io). Usa HTML y CSS y se puede abrir directamente con un navegador.

## Vista local

Abrí `dist/index.html`. El sitio funciona sin instalar dependencias ni ejecutar un comando de compilación.

## Personalización

- Editá el nombre, la descripción y los enlaces en `dist/index.html`.
- Para cambiar el retrato, reemplazá `dist/mauricio-gonzalez.png` o actualizá la ruta del archivo en `dist/index.html`.
- Cambiá los colores y el diseño en `dist/styles.css`.
- Reemplazá `dist/favicon.svg` si querés usar otro ícono de pestaña.

Los destinos se tomaron de la configuración del sitio personal y de los remotos Git del workspace.

Cuando elijas dónde publicarlo, usá `dist/` como carpeta raíz del sitio estático.
